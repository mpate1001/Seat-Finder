  <name>Task 1: scripts/verify-setup-split.mjs — TOOL-03 bundle-isolation grep gate</name>
  <files>scripts/verify-setup-split.mjs</files>
  <behavior>
    - ESM Node script. Mirrors scripts/verify-pwa-build.mjs shape (imports from 'fs' + 'path', clear error output, exit-code contract 0 or 1).
    - Paths: `const dist = resolve('dist', 'assets');` — fail fast if dist/ or dist/assets/ missing ("Did vite build run?").
    - Collect `jsFiles = readdirSync(dist).filter(f => f.endsWith('.js'))`.
    - Identify guest entry chunk(s): `entryCandidates = jsFiles.filter(f => /^index-[A-Za-z0-9_-]+\.js$/.test(f))` — fail if zero.
    - Forbidden-string list (case-INSENSITIVE match):
      ```js
      // Narrow, minification-resistant tokens. Dropped `createWorker` (too
      // generic — many unrelated deps export a helper with that name and would
      // false-positive on minified bundles). Dropped `SetupApp` (minifier may
      // rename the component, and the string might appear in an error stack
      // frame captured from anywhere). Replaced with Tesseract's runtime
      // config string `tessedit_char_whitelist` and the setup-only symbol
      // `runDetectionPipeline` — both survive minification and are unique.
      const forbidden = [
        'opencv',                    // package name (preserved in chunk metadata when loaded)
        'tesseract',                 // package name
        'HoughCircles',              // OpenCV API identifier (not minified across module boundary)
        'tessedit_char_whitelist',   // Tesseract config string literal — not minified
        'runDetectionPipeline',      // setup-only internal symbol
        'DraftPin',                  // setup-only type symbol
      ];
      ```
      Rationale:
      - opencv / tesseract — the two CV packages (RESEARCH §Code Examples + §Pitfall 8)
      - HoughCircles — cv API identifier; catches if the npm package is inlined under a different top-level name
      - tessedit_char_whitelist — literal Tesseract config key; proves OCR init landed
      - runDetectionPipeline — setup-only entry-point symbol
      - DraftPin — setup-only type; if it appears in guest chunk something from src/setup/types.ts leaked
    - For each entry candidate, read content, for each forbidden substring run `content.toLowerCase().includes(needle.toLowerCase())` — accumulate violations.
    - If violations: print formatted list "{file}: matched \"{needle}\"" and exit 1.
    - Identify setup chunks: `setupCandidates = jsFiles.filter(f => /setup|SetupApp/i.test(f))`.
    - Of those, confirm AT LEAST ONE contains 'opencv' OR 'tesseract' (case-insensitive) — this proves the split isn't tree-shaken into nothing. Fail (exit 1) otherwise with message "no setup chunk found containing opencv/tesseract — did the lazy import resolve during build?".
    - Success: print `verify-setup-split passed.` + list the clean entry files + list the setup chunk(s).

    Exit-code contract: 0 = isolated and split; 1 = violation OR chunk missing. CI fails on 1.
  </behavior>
